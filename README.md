# 🚌 Bus Driver Website

A fun and interactive **Bus Driver Simulator Website** created using HTML, CSS, and JavaScript.

## 🎵 Features

* 🚌 Bus driver interface
* 🎵 Music player
* ▶️ Play / Pause music
* ⏭️ Next and Previous song
* 🔊 Volume control
* 📯 Bus horn sound
* 🎨 Interactive and colorful design
* 📱 Responsive layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Audio (MP3)

## 📁 Project Structure

```text
Bus-Driver-Website/
│
├── index.html
├── style.css
├── script.js
│
├── music/
│   ├── song1.mp3
│   ├── song2.mp3
│   └── song3.mp3
│
└── sounds/
    └── horn.mp3
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Enjoy the Bus Driver Website! 🚌🎵
